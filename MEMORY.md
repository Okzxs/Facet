## Недавние решения
- [Фаза 4.10] Центрирование активной строки: LazyColumn измеряется через onSizeChanged, contentPadding = высота/2 − полстроки, scrollOffset = -центр; при открытии — мгновенный scrollToItem (activeIndex сбрасывается при смене текста)
- [Фаза 4.10] Стиль смягчён по просьбе пользователя: пружина 0.85, shadow blur 8 / alpha 0.2, вес 500→700, шиммер 0.2 при полосе 0.12, tipColor alpha 0.7
- [Фаза 4.9] Караоке-градиент строится по критическим точкам (кромка заливки ±2.8% + волна перелива ±9%) с компонентным смешением цветов; фон строки — smoothstep, фронт — тлеющее свечение highlightColor
- [Фаза 4.9] Одна пружина фокуса (dampingRatio 0.62) ведёт вес 600→800, масштаб 1.05 (TransformOrigin от левого края), свечение blur 3→16 и альфы строк (0.4 / 0.62 / 1.0)
- [Фаза 4.9] Перф: прогресс заливки читает только активная строка (лямбда в ветке `when`), шиммер — `rememberInfiniteTransition` внутри условия «активная + isPlaying»; неактивные строки имеют константную кисть
- [Фаза 4.9] `isPlaying` проброшен PlayerScreen → ExpressiveHeroZone → LyricsForeground → LyricsListView (шиммер замирает на паузе)
- [Фаза 4.9] Автоскролл — штатный `animateScrollToItem` foundation (кастомный animationSpec у API отсутствует), строка вынесена в отдельный композабл LyricLineItem
- [Фаза 4.8] Настройки хранятся в SharedPreferences (`mymusic_settings`) через `SettingsRepository` — без новой зависимости DataStore, отказ от изменения версий библиотек
- [Фаза 4.8] Тема от акцента: `accentColorScheme` генерирует primary-группу из seed через HSL (androidx ColorUtils), приоритет `accentColor != null` выше Dynamic Color
- [Фаза 4.8] «Динамические цвета обложки» управляют и палитрой плеера: выключено → `artworkUrl = null` в `rememberPlayerDynamicColors`, fallback строится из акцента темы
- [Фаза 4.8] ExpressivePlayerSlider: «цепочка точек» заменена на сплошную дорожку 8dp по просьбе пользователя (точки не читались как прогресс)
- [Фаза 4.7] 3 варианта компоновки в одном коде через `PLAYER_LAYOUT_VARIANT` (1 «Редакция» / 2 «Смещение» / 3 «На обложке») — переключение цифрой и пересборкой
- [Фаза 4.7] Обложка — постоянный слой-задник: при входе в тексты пружинно уменьшается, уходит вниз, тускнеет и в blur 26dp (Modifier.blur, реально работает на Android 12+)
- [Фаза 4.7] Управление собрано в плавающий «остров» (44/44/22/22) с приросшим сверху язычком «Текст»; скорость, пред/плей/след/очередь — внутри
- [Фаза 4.7] Слайдер «цепочка точек»: пройденные точки крупнее, точка у бегунка раздувается, ползунок пружинит с овершутом (dampingRatio 0.30); старый PlayerSlider удалён

## Установленные конвенции
- Архитектура: MVVM + Clean Architecture (Data / Domain / Feature / Core)
- UI: Jetpack Compose + токены Material 3 Expressive
- Среда: слабый ноутбук без эмулятора и Android Studio, сборка через Gradle CLI
- Версии: запрет на повышение AGP выше 8.5.2 и изменение версий библиотек
- Язык: комментарии в коде, служебные файлы (MEMORY.md, PROGRESS.md) и документация — строго на русском языке
