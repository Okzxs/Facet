# Facet Design Specification: Material 3 Expressive & Creative Identity

**Дата:** 16 октября 2026  
**Версия документа:** 1.0  
**Статус:** Утверждено для реализации (Фаза 0)  
**Фундамент:** Material Design 3 (M3 Expressive 2025–2026) + Эстетика `exteraless` / современных стриминговых медиасистем

---

## 1. Концепция и философия визуального языка

Facet объединяет строгость и адаптивность **Material 3 Expressive** с кинематографичной и эмоциональной эстетикой музыкального плеера. 

### Базовые принципы
1. **Dynamic Emotion**: Интерфейс откликается на музыку — адаптивное тонирование (Palette API) мягко заливает экран плеера, мини-плеер и hero-карточки оттенками текущего трека.
2. **Tactile Geometry**: Контраст скруглений — от супер-эллиптических сквирклов (18–28dp) до строгих пилюль (52dp контейнеры с составными радиусами) и плавных морфов кнопок при тапе.
3. **Typography as Art**: Крупная выразительная типографика (HeadlineLarge, DisplaySmall с плотным трекингом) в hero-секциях, жирные акценты на активных состояниях, мягкий контраст второстепенного текста.
4. **Living Motion**: Пружинная физика (`spring(dampingRatio = 0.78f, stiffness = Spring.StiffnessMediumLow)`), отсутствие резких скачков, бесшовный переход обложки между мини-плеером, плеером и режимом караоке.

## 2. Цветовая система и роли (Color Scheme)

Основана на M3 Dynamic Color (Android 12+) с богатой ночной палитрой fallback на violet/purple тонах.

### Цветовые роли контейнеров и поверхностей
| Роль токена | Назначение в Facet | Hex (Fallback Dark) |
|---|---|---|
| `surface` | Основной фон экранов и нижнего слоя | `#121216` |
| `surfaceContainerLowest` | Глубокий фон подложки | `#0D0E12` |
| `surfaceContainerLow` | Фон экранов Home, Library, шторки очереди | `#1A1A22` |
| `surfaceContainer` | Базовые карточки треков, фон NavigationBar | `#21212C` |
| `surfaceContainerHigh` | Приподнятые элементы, пилюли действий, кнопки | `#2B2B38` |
| `surfaceContainerHighest` | Активные переключатели, скелетоны при загрузке | `#363646` |
| `primary` | Акцентные кнопки (Play, активные ползунки, свечение караоке) | `#D0BCFF` |
| `onPrimary` | Текст/иконка на акцентных кнопках | `#381E72` |

### Динамическое тонирование (Player & MiniPlayer)
- Доминантный цвет обложки извлекается через `rememberPlayerDynamicColors` (кэш в памяти по URL, IO-поток).
- Вертикальный градиент: `[dominant.copy(alpha = 0.28f), surfaceContainerLow, surface]`.
- Плавный кроссфейд цветов при смене трека через `animateColorAsState(tween(500))`.

## 3. Геометрия и система форм (Shape Scale)

M3 Expressive делает упор на разнообразие форм:

| Компонент | Токен формы | Радиус / Параметры |
|---|---|---|
| **Full Player Cover** | Shape Large / ExtraLarge | `RoundedCornerShape(28.dp)` + shadow 14dp |

| **Like Button** | Expressive Squircle | `RoundedCornerShape(18.dp)`, 48×48 dp |
| **Play/Pause Center** | Dynamic Morph Button | `RoundedCornerShape(44.dp)` (пауза) $\leftrightarrow$ `28.dp` (плей), размер 88dp |
| **Prev / Next** | Circle / Squircle | `RoundedCornerShape(32.dp)`, 64×64 dp |
| **Action Pills Row** | Segmented Pill Bar | Высота 52dp; левая `26.dp/8.dp`, центр `8.dp`, правая `8.dp/26.dp` |
| **Queue Sheet** | Bottom Sheet ExtraLarge | Верхние углы `28.dp`, нижние `0.dp`, высота 78% экрана |
| **TrackCard** | Expressive List Item | Скругление карточки `16.dp`, обложка `12.dp` (56×56 dp) |
| **Carousel Cards (Home)** | Hero & Medium Cards | Hero: 220×140 dp (`24.dp`), Medium: 148×148 dp (`20.dp`) |
| **NavigationBar Indicator** | Active Pill Indicator | 64×32 dp, `RoundedCornerShape(16.dp)` |

## 5. Система движения (Motion & Physics)

Для достижения органичного, «живого» отклика интерфейса применяются спецификации M3 Expressive Motion:

### Спецификации анимаций
1. **Spring-физика для шторок и переходов**:
   - `spring(dampingRatio = 0.82f, stiffness = Spring.StiffnessMediumLow)` — мягкий возврат без резких отскоков для `PlayerQueueSheet` и перетягиваний.
2. **Схлопывание обложки в режим текста (Player)**:
   - Длительность 320 мс, кривая `FastOutSlowInEasing` (`CubicBezier(0.4, 0.0, 0.2, 1.0)`).
   - Синхронная интерполяция размера (280dp $\to$ 56dp) и радиуса углов (28dp $\to$ 16dp).
3. **Автоскролл текста караоке**:
   - Плавный скролл `animateScrollToItem` с центрированием строки.
   - Задержка после ручного скролла: 750 мс (`FOLLOW_RESUME_MS`), после чего фокус плавно возвращается к поющейся строке.
4. **Морф кнопки Play/Pause**:
   - Анимация формы `animateDpAsState(targetValue, tween(220, easing = FastOutSlowInEasing))`.
5. **Всплывающий MiniPlayer**:
   - Появление: `slideInVertically(spring(stiffness = Spring.StiffnessLow)) + fadeIn(tween(200))`.
   - Исчезновение: `slideOutVertically(tween(200)) + fadeOut(tween(150))`.

## 6. Выразительные решения по экранам (Screen Patterns)

### 1. Главный экран (Home)
- **Шапка-приветствие**: динамический текст по времени суток («Доброе утро», «Добрый день», «Добрый вечер», «Доброй ночи») + крупная иконка настроения.
- **Hero-блок («Быстрый старт»)**: компактная сетка 2×2 или горизонтальная карусель последних 4 прослушанных треков с крупными обложками и кнопкой быстрого воспроизведения одним тапом.
- **Тематические карусели (`LazyRow`)**:
  - «Твои жанры» — карточки с градиентной подложкой цвета жанра и вырезанной виниловой иконкой.
  - «В тренде SoundCloud (Top 50)» — номерные карточки с позицией в чарте (1, 2, 3… полупрозрачным крупным шрифтом на фоне).
- **Скелетоны**: формализованные мерцающие плашки карточек и каруселей при первой загрузке.

### 2. Экран поиска (Search)
- **Expressive SearchBar**: закругленный контейнер (28dp), приподнятый над контентом, с плавной анимацией фокуса.
- **Чипсы быстрого выбора**: фильтры популярных жанров (Electronic, Hip-Hop, Rock, Chill, Pop) для мгновенного поиска.
- **TrackCard**: M3 ListItem с мягким hover/press-эффектом (tonal ripple), отображением длительности и кнопкой контекстного меню.

### 3. Библиотека (Library)
- **Табы переключения**: «Любимые треки», «История прослушиваний».
- **Большой счетчик**: «42 трека в вашей коллекции» с выразительной графикой пустых состояний при отсутствии сохранённых треков.
- **Быстрый Shuffle**: плавающая или закрепленная кнопка «Перемешать всё» вверху списка.

### 4. Моя волна (Wave)
- **Expressive Teaser**: не сухая надпись «В разработке», а анимированная пульсирующая сфера или звуковая волна (`Canvas` с плавной синусоидой), отражающая будущий интеллектуальный поток треков.
- Описание концепции персональной бесконечной волны рекомендаций.

### 5. Полноэкранный плеер (Player)
- Двухслойный холст: динамический тонированный фон + контент.
- Схлопывание обложки в режим караоке с синхронизированным свечением строк.
- Контроллеры сквирклов, таймеры со знаком минус (`"-m:ss"`), сегментированные пилюли действий.

### 6. Шторка очереди (PlayerQueueSheet)
- Высота 78%, скругление верхних углов 28dp.
- Драг-хэндл 32×4 dp с alpha 0.45.
- Подсветка текущего трека тонированной плашкой с анимированной миниатюрой эквалайзера.
- Свайп влево для удаления трека из текущей очереди.

## 7. Творческие решения и их обоснование

| Решение | Обоснование |
|---|---|
| **Решение 1: Номерные карточки в чартах «Top 50»** | В чартах пользователю критически важна позиция трека. Огромная полупрозрачная цифра (Display Large, alpha 0.15) за обложкой дает выразительный плакатный вид без загромождения метаданных. |
| **Решение 2: Сегментированный бар пилюль 52dp в плеере** | Объединение кнопок «Скорость», «Текст» и «Далее» в единый тактильный модуль снижает визуальный шум, создает ощущение цельного пульта управления и точно следует референсу `exteraless`. |
| **Решение 3: Сквиркл лайка 18dp с цветовым заполнением** | Стандартная круглая кнопка теряется рядом с длинными названиями. Сквиркл 48×48 dp создает четкий визуальный якорь и тактильно удобен для быстрого нажатия одной рукой на ходу. |
| **Решение 4: Динамический градиент от обложки в плеере** | Черный фон кажется скучным и холодным. Вытяжка доминантного цвета через Palette погружает слушателя в атмосферу альбома, сохраняя при этом читаемость белого текста за счет затемнения снизу. |
| **Решение 5: Живая синусоида для тизера «Моя волна»** | Заглушка «Скоро» разочаровывает. Плавная процедурная анимация волн в Canvas передает ощущение живой музыки и подогревает интерес к грядущей фиче без сторонних тяжелых Lottie-файлов. |
