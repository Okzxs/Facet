# Разбор чартов Dotify (A26, com.dotify.app 1.2.6)

## Что внутри APK

- Dotify — **Flutter**: 42 МБ APK, `lib/arm64-v8a/libapp.so` 12.8 МБ, `libflutter.so`, assets `flutter_assets`.
- Java-слой почти пуст, UI и логика — Dart AOT; JADX даёт только оболочку и плагины.
- Строки Dart-снапшота: `https://api.dotify.fun`, `/home`, `charts`, `charts_tracks`, `home.charts`, `ChartCategory`, `ChartsSection`.
- Чарты — **не прямой SoundCloud-запрос из клиента**: приложение берёт готовые подборки с собственного backend `api.dotify.fun`. Прямой curl `/home` с любым User-Agent возвращает HTTP 444 (WAF/подпись клиента), поэтому данные Dotify нельзя переиспользовать.

## Как выглядят чарты в UI

- Экран «Чарты» — 4 горизонтальные страницы с индикатором-точками:
  1. **Треки** — 10 строк: номер 1–10, квадратная обложка, название, артист.
  2. **Плейлисты** — 10 строк: номер, обложка, название, автор.
  3. **Артисты** — 10 строк: номер, круглая аватарка, имя, подписчики.
  4. **Альбомы** — 10 строк: номер, обложка, название, артист.
- Строки без карточек, плотные, на чёрном фоне; свайп влево/вправо переключает страницу.
- Данные подобраны под регион/вкус (BY/RU), поэтому треки Dotify (`type london`, `sleep mode`, `ONDA ANDAR`) не совпадают с глобальным SoundCloud Top 50 (`GOOSE COAT`, `Nafe Smallz`).

## Что исправлено в Facet

- Home-чарты больше не показывают 10 крупных карточек с горизонтальным скроллом: теперь **пейджер по 5 компактных строк** с номерами и точками, как в Dotify; свайп листает страницы.
- Убран фильтр `viewCount == 0` — он выбрасывал валидные новые треки из чарта.
- Источник — SoundCloud Top 50 с региональным параметром `country=BY`; fallback на кэш остался.
- Точную копию данных Dotify сделать нельзя без их закрытого API; наша реализация остаётся независимой и использует SoundCloud.

## Ограничения

- Dotify backend отвечает 444 на прямые запросы; авторизация/подпись клиента не документированы.
- Страницы Playlists/Artists/Albums у Facet не дублируются: для них нет независимого источника, а подделывать данные нельзя.
