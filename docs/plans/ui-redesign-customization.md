# Facet: дорогой UI, кастомизация и жест закрытия плеера

Дата: 24.11.2026  
База: `main` на `f115c11`  
Цель: не «ещё один MD3», а узнаваемый премиальный плеер с глубокой персонализацией и без потери лёгкости.

---

## 1. Принципы

1. **Один яркий момент на экран.** Обложка, hero-карточка или строка текста несут цвет и характер; хром (навигация, кнопки, подписи) остаётся тихим.
2. **Дорого = точно, а не блестяще.** Никаких градиентных текстов, свечений, эмодзи-иконок, стекла и парящих шаров. Дорогое ощущение дают сетка, типографика, воздух, тактильность и скорость.
3. **MD3/Expressive, но со своим лицом.** Используем токены, формы, пружины, динамический цвет; уникальность — в арт-дирекшне, а не в самодельных контролах.
4. **Кастомизация — пресетами, не россыпью тумблеров.** Пользователь выбирает готовые стили и тонко правит то, что реально влияет; всё хранится в одном профиле и переносится.
5. **Лёгкость.** APK ≤ ~40 МБ, без Haze/ONNX/тяжёлых нативных библиотек. Новый шрифт — максимум ~0,3 МБ.

### Направление (черновик)

- **Продукт:** кросс-сервисный плеер для тех, кто собирает музыку по разным платформам.
- **Характер:** тихий, тактильный, коллекционный. Не «неоновая тусовка», а личная полка.
- **Мир:** вечерняя комната, винил, тёплый свет, бумажные конверты. Отсюда графит/чернила, тёплый латунный акцент, бумажный офф-вайт.
- **Моменты:** полноэкранная обложка в плеере, hero «Продолжить» на главной, активная строка текста.
- **Подпись:** «каталожный индекс» — тонкая латунная линия и номер секции/трека (01, 02), как на конверте пластинки. Одно место на экран, не декор ради декора.

**Палитра по умолчанию (Signature, не динамическая):**  
Ink `#0E0F12`, Graphite `#17191E`, Bone `#F4F1EA`, Brass `#C8A46A`, глубокий янтарь `#A8792F`.  
Светлая: Paper `#F7F4EE`, Ink `#141416`, Brass `#8A6A34`.  
Dynamic Color остаётся режимом, но по умолчанию — Signature.

**Типографика:** Google Sans Flex для интерфейса; для крупных заголовков/имени артиста — акцидентный serif (Fraunces variable, встроенный, ~0,2 МБ) после A/B на устройствах. Если на A26 выглядит чужеродно — оставляем один Google Sans Flex с другой шкалой.

## 2. Что чиним сразу: жест закрытия плеера

Сейчас закрытие требует протащить палец почти через весь экран. Нужно:

- порог закрытия: `min(120.dp, 18% высоты)` **или** скорость вниз ≥ 900 dp/s — жест «бросок» закрывает сразу;
- жест работает с шапки/обложки, не конфликтует с вертикальным скроллом шторок и слайдером;
- настройка чувствительности в «Внешний вид → Жесты»: низкая/средняя/высокая;
- обратная анимация закрытия не должна ждать полного пути: если порог пройден, плеер уезжает с текущей скоростью;
- тест: 80 dp drag, 150 dp drag, fling, drag вверх (не закрывает), drag по слайдеру (не закрывает).

## 3. Исследование конкурентов

### Открытые исходники (читаем код и UI)

- Dotify (Flutter, GitHub) — очередь, sleep timer, контекст «Playing from», кастомизация мини-плеера.
- Riff (Electron, GitHub) — MD3-токены, очередь, восстановление сессии.
- Auxio (Android/Kotlin) — строгая библиотека, настройки сканирования, тема.
- Metro / Retro Music / Gramophone / Namida — списки, плеер, темы, виджеты (лицензии проверить).
- Musicolet и Symfonium — только публичные скриншоты/документация, без декомпиляции.

### Закрытые приложения

Poweramp, Stellio, Oto Music, YouTube Music, Samsung Music, Spotify, Apple Music — только магазины/скриншоты/публичные гайды.  
REA/декомпиляция — **только если пользователь даст APK и только для инвентаризации взаимодействий**, без копирования кода, ассетов и текстов. GPL-код (если попадёт) — с атрибуцией в `NOTICE`, Facet уже GPLv3.

### Что ищем

- пресеты тем и как они устроены (не просто цвет, а surfaces/контраст);
- варианты плеера (обложка/компакт/текст), формы обложки, поведение мини-плеера;
- настройки жестов и порогов;
- организация «студии оформления»: превью, живой пример, сброс;
- эквалайзер: кривые, кастомные полосы, presets;
- очередь, «играет из», сон-таймер, виджеты;
- пустые состояния, онбординг, тексты.

**Артефакт:** `docs/research/music-apps-ux.md` — матрица «паттерн → где видел → берём/не берём → почему», со ссылками и лицензиями.

### Скиллы

- `ui-ux-pro-max` — продукт/стиль/палитра/типографика/UX-правила, `--design-system` + точечные запросы.
- `unslop` — обязательный аудит каждого ключевого экрана до/после, направление из пяти строк, девять проходов.
- `material-design-3-expressive` — токены, пружины, доступность.
- `ui-styling` — только как справочник по токенам/контрасту, не для Android-кода.

## 4. Технический фундамент

### 4.1. Токены вместо разрозненных значений

Новый слой `core/ui/design`:

- `FacetColors`: роли surface/onSurface/outline/accent/positive/warning, отдельно для Signature, Dynamic, presets, AMOLED.
- `FacetTypography`: display/headline/title/body/label + emphasized + lyric scale.
- `FacetShapes`: радиусы 4/8/12/16/20/28 + nested radius.
- `FacetSpacing`: 4/8/12/16/20/24/32/48 + density multiplier.
- `FacetMotion`: durations 90/160/240/360, expressive springs, reduced-motion.
- CompositionLocals: `LocalFacetSpacing`, `LocalFacetMotion`, `LocalFacetDensity`.

Правило: новые экраны не используют сырые `dp`/`Color`/`tween`, только токены.

### 4.2. Профиль оформления

`AppearanceProfile` (JSON, DataStore/SharedPreferences, версия схемы):

```text
schemaVersion
themeMode, paletteMode, customAccent, contrast, amoled
fontScale, displayFont, lyricSize, lyricWeight
shapeScale, density, cardStyle
motionScale
playerLayout, coverShape, coverSize, backdrop, progressStyle, controlsStyle
miniPlayerStyle, dockStyle, dockLabels
homeSections[], homeHeroStyle
libraryLayout
gestureSensitivity, doubleTapAction
eqPreset, eqBands, limiter, skipSilence
```

- миграции с текущих `AppSettings`;
- импорт/экспорт JSON, «поделиться стилем»;
- сброс к Signature;
- пресеты: Signature, Night Jazz, Paper, Mono, Dynamic.

### 4.3. Компонентная библиотека

`FacetHero`, `FacetCard`, `FacetListRow`, `FacetSectionHeader`, `FacetDock`, `FacetSheet`, `FacetButton`, `FacetSegmented`, `FacetSlider`, `FacetEmptyState`, `FacetSettingsRow`.  
Один набор форм/отступов/состояний; старые локальные копии постепенно заменяются.

### 4.4. Производительность

- Бюджет: A26 p99 ≤ 16 мс на скролле, MI 8 без устойчивого jank; baseline profile.
- Анимации — только `transform/alpha`, без layout-свойств и больших blur.
- Проверка `gfxinfo` до/после каждого этапа.

## 5. Кастомизация: что даём пользователю

### Студия оформления (новый экран)

1. **Тема:** System / Light / Dark / AMOLED; контраст Standard/Medium/High.
2. **Палитра:** Dynamic, Signature, 6 пресетов, свой акцент, «тонировать поверхности».
3. **Типографика:** масштаб 85–130%, display-шрифт (Sans/Serif), размер и жирность текста.
4. **Форма:** радиус (Subtle/Soft/Round), стиль карточек (Flat/Hairline/Elevated), плотность.
5. **Движение:** Full/Reduced/Off, скорость.
6. **Плеер:** Artwork-first / Compact / Lyrics-first; форма и размер обложки; backdrop blur; стиль прогресса (wave/line); island/classic; показывать источник/качество; мини-плеер.
7. **Жесты:** чувствительность закрытия, double-tap (seek/like), свайп вверх (очередь), свайп по обложке.
8. **Навигация:** плавающий/прикреплённый док, подписи всегда/выбранная, порядок и скрытие вкладок, порог rail.
9. **Главная:** порядок и видимость секций, стиль hero, «Продолжить» вкл/выкл.
10. **Медиатека:** сетка/список, размер обложек, стиль карточки лайков.
11. **Текст:** размер, межстрочный, выравнивание, blur, glow/sweep, фон, перевод, офсет, провайдер.
12. **Звук:** EQ-пресеты и кастомные полосы, лимитер, тишина.
13. **Система:** кнопки уведомления, виджеты 4×2/2×2 (отдельный этап), профиль настроек.

### Пресеты

- **Signature** — графит + латунь, serif-акценты, крупные hero.
- **Night Jazz** — глубокий синий/виноград, тёплый янтарь, мягкие формы.
- **Paper** — светлая бумага, чернила, минимум цвета.
- **Mono** — ахроматика, строгая сетка.
- **Dynamic** — обои пользователя.

Пользователь может править пресет и сохранять свой; экспорт/импорт JSON.

## 6. Арт-дирекшн по экранам

- **Home:** hero «Продолжить» (уже нравится) как главный момент; секции с каталожными номерами; никаких пёстрых карточек.
- **Player:** обложка — главный объект; два-три варианта компоновки; аккуратные кнопки действий; источник/качество — тихая строка; отказ от лишних пилюль.
- **Lyrics:** премиальная типографика, крупная активная строка, мягкое затухание, настройки размера/фона; без «караоке-неона».
- **Library:** редакционная сетка, крупные обложки, спокойные пустые состояния.
- **Search:** поле-витрина, чипсы источников, карточки артистов; состояния без обрезки.
- **Artist:** hero-баннер, популярное, релизы, подписка; единые компоненты с Home.
- **Import:** один хаб, четыре вкладки, понятные шаги Takeout/профиля, прогресс и результат.
- **Settings:** «Студия оформления» + обычные настройки; поиск по настройкам; живые превью.
- **Onboarding:** 3 экрана-обещания (все источники, волна, текст), выбор стартовой темы, без стены текста.

## 8. Ограничения и риски

| Риск | Мера |
|---|---|
| Комбинаторный взрыв настроек | пресеты + токены, не отдельный код на каждый вариант |
| Дизайн «поехал» на светлой/тёмной | golden-скриншоты, контраст-чек, ручной прогон |
| Тормоза на A26 | бюджет p99, gfxinfo после каждого этапа, без тяжёлых blur |
| Потеря данных/настроек | версия профиля, миграции, экспорт перед изменениями |
| Чужой код/ассеты | только идеи; GPL-атрибуция, если код реально переносится |
| APK > 40 МБ | шрифт ≤0,3 МБ, без Haze/ONNX, контроль размера |
| Жест конфликтует со скроллом | отдельные зоны, velocity-порог, тесты |

---

## 9. Критерии готовности

- Жест закрытия срабатывает на 80–150 dp и на fling, не мешает скроллу.
- Есть минимум 5 пресетов + свой, всё сохраняется и переносится JSON.
- Светлая/тёмная/AMOLED без провалов контраста; шрифт 2.0 не ломает экраны.
- Home/Player/Library/Search/Import/Settings выглядят как один продукт.
- A26: p99 скролла ≤ 16 мс; MI 8: без устойчивого jank.
- 444+ тестов зелёные, APK в бюджете.
- `docs/design/facet-design-system.md` и `docs/research/music-apps-ux.md` обновлены.

---

## 10. Что не делаем

- Haze, mesh-фоны на весь экран, ONNX, Automix.
- Копирование чужих ассетов/кода без лицензии.
- Кастомизацию ради кастомизации: каждая настройка должна менять ощущение или сценарий.
