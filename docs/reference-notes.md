# Reference Notes: MD3 Player & Lyrics (exteraless)

Выжимка архитектурных решений, метрик, цветовых ролей, алгоритмов и таймингов из форка Telegram (exteraless, beta 14).
*Примечание: Дословное копирование кода запрещено (GPL). Ниже представлены чистые спецификации паттернов для реализации на Jetpack Compose.*

---

## 1. LRC и тексты песен (LRCLIB & парсинг)

### Формат и парсинг
- **Регулярные выражения**:
  - Метка времени строки: `\[(\d{1,3}):(\d{1,2})(?:[.:](\d{1,3}))?\]` (поддержка `mm:ss`, `mm:ss.xx`, `mm:ss.xxx`).
  - Метка смещения: `^\[offset:\s*([+-]?\d+)\s*\]` (смещение всего трека в мс).
  - Внутристрочные тайминги слогов (караоке): `<\d{1,3}:\d{1,2}(?:[.:]\d{1,3})?>` — вырезаются при парсинге построчного текста.
  - Метаданные (например, `[ar:...]`, `[ti:...]`): игнорируются при построении списка строк.
- **Преобразование времени в миллисекунды**:
  - Минуты * 60 000 + секунды * 1 000.
  - Доли секунд: 1 цифра = `f * 100`, 2 цифры = `f * 10`, 3 цифры = `f`.
  - Коррекция: `Math.max(0, time - offset)`.
- **Сортировка и фильтрация**:
  - Строки сортируются по времени возрастания: `line.time`.
  - Схлопывание пустых строк-дубликатов.
  - Фолбэк на обычный текст (plain lyrics), если нет ни одной временной метки (`time = -1`).
- **LRCLIB API**:
  - Эндпоинт поиска: `https://lrclib.net/api/get?artist_name={artist}&track_name={title}&duration={duration_sec}`.
  - Резервный поиск: `https://lrclib.net/api/search?track_name={title}`.
  - Поля ответа: `syncedLyrics` (строка LRC), `plainLyrics` (обычный текст), `instrumental` (булево).

### Поведение текста в UI
- **Выбор текущей строки**:
  - Бинарный поиск или поиск последнего индекса, где `line.time <= currentPlaybackMs`.
- **Роли строк и визуал**:
  - `ROLE_ACTIVE` (текущая): масштаб 1.05x, непрозрачность 1.0 (100%), акцентный цвет `onSurface`.
  - `ROLE_PAST` (прошедшие): непрозрачность 0.50 (50%), масштаб 1.0x, цвет `onSurface`.
  - `ROLE_FUTURE` (будущие): непрозрачность 0.51 (51%), масштаб 1.0x.
- **Тап по строке**:
  - Немедленная перемотка: `seekTo(line.timeMs)`.
  - Сброс ручного скролла: плеер сразу возвращается в режим слежения.
- **Автоскролл и взаимодействие пользователя**:
  - При ручном скролле пользователем автоскролл приостанавливается.
  - Возобновление слежения (follow resume): через 750 мс (`FOLLOW_RESUME_MS`) после остановки скролла.
  - Центрирование активной строки в списке с плавной анимацией скролла.
- **Градиентные края**:
  - Верхний fade: градиент высотой 32dp.
  - Нижний fade: градиент высотой 40dp.

## 2. Экран плеера (MD3 Player)

### Размеры и отступы
- **Скругление углов шторки/экрана**: 28dp (в свернутом виде) / адаптивно.
- **Обложка альбома**:
  - В развернутом режиме: квадратная, радиус скругления 28dp, тень/elevation 14dp.
  - В режиме текста: плавно схлопывается в миниатюру 56×56 dp с радиусом скругления 16dp.
- **Текстовые блоки**:
  - Заголовок трека: 26sp, bold.
  - Артист: 16sp, regular, цвет `onSurfaceVariant`.
  - Миниатюра в режиме текста: заголовок 18sp bold, артист 14sp.
- **Кнопка лайка**:
  - Размер 48×48 dp, сквиркл/круг (радиус 24dp), отступ от текста 12dp.

### Кнопки управления (ControlsRow)
- **Габариты кнопок (ширина / высота)**:
  - Shuffle / Repeat: 48×48 dp (радиус 24dp; при активации морфинг в 14dp).
  - Prev / Next: 64×64 dp (радиус 32dp; при нажатии расширение до 76dp и радиус 18dp).
  - Play / Pause: 88×88 dp (радиус 44dp в паузе / 28dp в воспроизведении / 20dp при нажатии; ширина при нажатии расширяется до 100dp).
- **Плавающее взаимодействие (morph/squish)**:
  - При нажатии на соседние кнопки (prev/next) Play сжимается до 80dp; при нажатии на Play — соседние сжимаются до 58dp.

### Пилюли действий (Group Actions)
- Контейнер высотой 52dp, горизонтальный ряд из 3 кнопок:
  1. **Скорость (Speed)**: левая кнопка, левый радиус 26dp, правый 8dp. Циклическое переключение (1.0x, 1.25x, 1.5x, 2.0x, 0.5x).
  2. **Текст (Lyrics)**: центральная кнопка, симметричный радиус 8dp. Переключает режим отображения обложки и текстов.
  3. **Очередь (Queue)**: правая кнопка, левый радиус 8dp, правый 26dp.

## 3. Мини-плеер (PlayerMiniView)

- **Высота**: 64dp.
- **Отступы**: горизонтальные 12dp, нижний 12dp над навигацией.
- **Скругление карточки**: 20dp, elevation 6dp.
- **Обложка**: 44×44 dp, радиус скругления 12dp.
- **Кнопки управления**: RingPlayButton (круговой прогресс вокруг Play/Pause) + Next + Close.

---

## 4. Очередь (PlayerQueueSheet)

- **Высота шторки**: ~78% экрана (`height * 0.78f`).
- **Скругление**: верхние углы 28dp, плоский низ.
- **Индикатор перетаскивания (Handle)**: 32×4 dp, радиус 2dp, полупрозрачный `onSurfaceVariant` (alpha ~45%).
- **Фон**: `surfaceContainerLow` / `surfaceLow`.
- **Подсветка активного трека**: тонированная плашка `secondaryContainer` / `primaryContainer` с акцентным цветом и иконкой воспроизведения.

---

## 5. Цветовые роли (Material Design 3 Dynamic Scheme)

- **Фон плеера**: `surface` / `surfaceContainerLow`.
- **Элементы управления**:
  - Play/Pause: `primary` фон, `onPrimary` иконка.
  - Дополнительные кнопки (Prev, Next, Shuffle, Repeat): `surfaceContainerHigh` или прозрачный с `onSurface`.
  - Пилюли внизу: `surfaceContainer` (неактивные) / `secondaryContainer` (активные, например активный режим текста).
  - Слайдер прогресса: активная дорожка `primary`, неактивная `surfaceVariant` / `outlineVariant`.

---

## 6. Анимации и кривые

- **Интерполятор**: `CubicBezierInterpolator(0.2, 0.0, 0.0, 1.0)` (Emphasized Decelerate) для открытия/закрытия и переходов режимов.
- **Длительности**:
  - Схлопывание обложки в миниатюру: 250–300 мс.
  - Появление подсказки времени (bubble) при seek: 150 мс (alpha + scale 0.8 -> 1.0).
  - Переключение режимов кнопок и радиусов: 180–220 мс.
  - Возобновление автоскролла после ручного скролла: задержка 750 мс, затем плавный скролл к позиции.
