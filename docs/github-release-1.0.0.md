## Facet 1.0.0

Первый релиз музыкального агрегатора Facet: SoundCloud, YouTube, Deezer,
Apple Music и Spotify в одном приложении на каноничном Material 3.

### Что внутри

- **Пять источников и сводный поиск.** Ищите сразу везде: результаты
  сливаются по артисту и названию, а бейдж «+N» показывает, где трек нашёлся
  ещё.
- **Медиатека.** Любимые треки, плейлисты и скачанное в одном месте. Импорт
  плейлистов по ссылке, импорт публичных профилей Spotify и SoundCloud,
  импорт списком «Артист - Название», лайки SoundCloud через публичный api-v2
  без лимита 200 и с порядком как в SoundCloud. После первого импорта
  FAB и блок Spotify скрываются.
- **Плеер.** Волна от трека, детюн 428–453 Гц, вариации Speed Up / Slowed /
  Nightcore, таймер сна, очередь с секциями и восстановлением после перезапуска.
  Переключение треков свайпом по обложке (вверх/вниз), кнопка текста на панели,
  обложки в максимальном доступном качестве.
- **Офлайн.** Скачивание с выбором качества 128/256/320 и ID3-тегами, кэш
  прослушанного на 500 МБ с LRU-очисткой.
- **Оформление.** Dynamic Color, fallback `#3A4E6E`, адаптивная иконка «Призма»,
  онбординг и сплэш Android 12+. Плавные анимации списков, карточек и
  появления элементов.

### Установка

Скачайте `app-release.apk` и установите на Android 8.0+ (API 26). Приложение
распространяется только как APK: публикация в сторах невозможна из-за парсинга
стриминговых сервисов.

- Файл: `app-release.apk`, 6 518 329 байт
- SHA-256: `bd61317908792a0e6a92a585958990cb8649c7cd8dc64502e52b27fcd23e417d`
- versionName `1.0.0`, versionCode `1`

Проверить контрольную сумму на Windows:

```powershell
Get-FileHash .\app-release.apk -Algorithm SHA256
```

### Известные ограничения

- Deezer и Apple Music — превью 30 секунд; полный трек подтягивается с YouTube.
- Spotify-вход нужен для метаданных и импорта; звук Spotify недоступен.
  С 11.02.2026 новый Development Mode Client ID требует Spotify Premium
  (один Client ID и до 5 пользователей).
- Импорт любимых SoundCloud работает для публичных профилей через `api-v2` и
  публичный `client_id`; закрытый профиль лайки не отдаёт.
- Slowed меняет скорость и питч, без reverb.
